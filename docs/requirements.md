# 訪問薬剤管理指導報告書アプリ 要件定義書

## 1. プロジェクト概要
**プロジェクト名**: 訪問薬剤管理指導報告書作成アプリケーション
**目的**: 訪問薬剤管理指導業務において、効率的に報告書を作成・管理し、多職種連携をスムーズに行うためのアプリケーションを開発する。

## 2. ユーザー
- **主な利用者**: 在宅医療を行う薬剤師
- **利用シーン**: 薬局内でのＰＣ入力、または訪問先でのタブレット入力

## 3. 機能要件

### 3.1 報告書作成・保存
以下の項目を含む報告書のデータ入力、編集、およびクラウドデータベースへの保存。

#### 基本情報
- **患者氏名**
- **生年月日**
- **性別**
- **主治医**
- **処方日**
- **調剤日**
- **訪問日**
- **担当薬剤師**

#### 薬剤管理状況
- **服薬コンプライアンス** (飲み忘れ、飲み残しの有無など)
- **残薬確認** (実際の残数など)
- **保管状況** (温度、湿度、整理状況など)

#### 指導内容
- **服薬指導** (患者・家族への説明内容)
- **副作用確認** (自覚症状の有無、バイタル変化など)

#### 次回計画
- **次回訪問予定**

### 3.2 閲覧・管理機能
- **一覧表示**: 作成済み報告書および患者のリスト表示
- **ソート機能**: 担当薬剤師、訪問日での並び替え
- **履歴参照**: 患者ごとの過去の報告書履歴の閲覧

### 3.3 出力機能
- **PDF作成**: 印刷およびFAX送信用のA4帳票形式でのPDF出力

## 4. 非機能要件
- **データ保存**: クラウドデータベース (Supabase) を使用し、永続化
- **セキュリティ**: ユーザー認証 (Supabase Auth) を実装し、患者情報を保護
- **UI/UX**: モダンで直感的な操作性、リッチなデザイン (Vanilla CSS / Animated)
- **デバイス**: PCおよびタブレットでのレスポンシブ対応

## 5. 技術スタック
- **Frontend**: Vite, React, TypeScript
- **Backend / Database**: Supabase (PostgreSQL, Auth)
- **Styling**: Vanilla CSS (Premium & Responsive Design)
- **Deployment**: Vercel (想定)
