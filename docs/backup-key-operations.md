# 薬局キー運用手順

## 目的

薬局キーは、自動バックアップとアップデート前バックアップを復元するための薬局単位の鍵です。PC故障時にPC内の設定だけへ依存しないよう、導入管理者側で薬局ごとに控えます。

## 台帳へ控える

1. ローカルアプリで「設定」を開く。
2. 「薬局キー」の「台帳用」を押す。
3. 管理者の台帳に貼り付ける。
4. 台帳はGoogle Driveなど、PC故障時にも参照できる場所へ保管する。

台帳の列:

- 控え日時
- 薬局名
- 所在地
- TEL
- FAX
- 薬局キー

## 再発行

薬局キーが漏えいした、または管理上の理由で変更する場合だけ再発行します。

1. 現在の薬局キーを台帳へ控えていることを確認する。
2. 「再発行」を押す。
3. 確認ダイアログを読んで続行する。
4. 再発行後、もう一度「台帳用」を押して新しい行を台帳へ追記する。

注意:

- 旧キーで作成済みの自動バックアップ/アップデート前バックアップは、旧キーがないと復元できません。
- アプリは旧キーを履歴保存しません。旧キーは管理者台帳で管理します。

## 復元

通常の手動バックアップは、作成時に入力したバックアップパスワードで復元します。

自動バックアップまたはアップデート前バックアップは、台帳に控えた薬局キーを復元パスワード欄へ入力して復元します。

復元時の確認:

- 対象薬局のバックアップファイルであること。
- バックアップ作成日時が復元したい時点に合っていること。
- 復元後、患者数/報告書数などのサマリーが想定と大きくずれていないこと。
- 復元前DB退避先が表示されたら、復元作業記録に控えること。
